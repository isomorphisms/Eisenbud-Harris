# Algebra ↔ geometry dictionary

This file is the reusable spine connecting Eisenbud's commutative algebra to scheme language.

| Algebra | Geometry | What a point picture can lose |
| --- | --- | --- |
| prime ideal `p` | point of `Spec A` | generic/nonclosed behavior if only maximal ideals are kept |
| maximal ideal | closed point in familiar settings | residue-field extensions |
| localization `A_f` | functions on basic open `D(f)` | global glue |
| localization `A_p` | local ring at `p` | neighborhood data if replaced by the residue field |
| quotient `A/I` | closed subscheme `V(I)` | nilpotents if replaced by `V(rad I)` |
| radical `rad I` | reduced support | multiplicity and embedded structure |
| nilpotent | infinitesimal thickening | completely invisible in ordinary support |
| associated prime | component/embedded algebraic position | embedded points/components |
| primary decomposition | decomposition with embedded/multiplicity data | scheme structure between visible components |
| tensor product `B ⊗_A C` | affine fiber product/base change | family/base information |
| residue field `κ(p)` | field of the point | arithmetic structure |
| graded ring | projective coordinate algebra | grading/projective scaling |
| `Proj S` | projective scheme | no single affine chart sees the whole object |
| graded module | sheaf data | module relations if only support is shown |
| free resolution | syzygetic/projective invariants | higher relations |
| Jacobian/rank conditions | tangent/singular/degeneracy loci | multiplicities and higher-order structure |
| initial/local leading terms | tangent cone / degeneration data | nonlinear local structure |
| Hilbert polynomial | dimension/degree/family invariant | finer geometry |
| Rees algebra | blow-up | exceptional-direction data |
| Fitting ideal | rank/degeneracy locus of a module | module structure if reduced too early |
| elimination ideal | image/projection equations | source-fiber information |
| flatness | controlled variation in a family | special-fiber pathologies |
| `Hom(T,X)` | T-valued points | infinitesimal/family information if T is restricted to fields |

## Repeated warning

The map from scheme structure to an ordinary picture is many-to-one.

For every visual example, ask which algebraic information was collapsed to make the image. Record that information beside the render.
