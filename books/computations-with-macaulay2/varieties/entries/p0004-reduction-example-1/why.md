# Why this polynomial appears

After the curve/surface intersection has been converted into a Gröbner-basis/leading-term computation, the chapter tests reduction of an explicit polynomial modulo the intersection ideal.

The point is computational rather than visual: the polynomial gives a concrete input whose normal form can be inspected. It belongs in the catalog anyway because the catalog's rule is “every explicit polynomial”, not only equations introduced as named varieties.

The Unicode display keeps explicit multiplication as `×`; the exact Macaulay2 spelling remains in `macaulay2.txt`.
