# Why this polynomial appears

This is the second generator of the book's opening curve ideal. Taken alone it is another hypersurface in affine three-space. Taken simultaneously with `x⁴ − y⁵`, it helps cut the ambient three-space down to the object whose dimension, codimension, degree, saturation, and radical the chapter investigates.

The catalog keeps the generator separate from the resulting curve because a system is not the same mathematical object as any single defining polynomial. It also gives SURFER a directly renderable object while preserving the intersection/system separately.
