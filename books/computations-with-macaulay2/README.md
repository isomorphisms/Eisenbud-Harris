# Computations in Algebraic Geometry with Macaulay 2

**Edited by David Eisenbud, Daniel R. Grayson, Michael Stillman, and Bernd Sturmfels. Algorithms and Computation in Mathematics 8, Springer, 2002.**

Publisher/DOI: https://doi.org/10.1007/978-3-662-04851-1

## Role here

Use this as the computational companion to the main Eisenbud spine. The point is not a detached software tutorial: keep experiments tied to ideals, varieties, projective geometry, homological algebra, monomial ideals, resolutions, sheaf algorithms, and the geometry being studied.

When a claim from the reading can be checked mechanically in a small example, prefer a reproducible Macaulay2 experiment plus an explanation of exactly what it verifies.

## Polynomial and variety catalog

The exhaustive catalog lives in [`varieties/`](varieties/).

It records every explicit polynomial and every explicit variety/scheme/ideal/system found in the book, keeps defining components as separate entries, records deterministic provenance, adds agent-written mathematical context, and exposes SURFER-render coverage. Its README is generated by a script in that directory.
